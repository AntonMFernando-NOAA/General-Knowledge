## How this book is organized

Each part lives in its own folder under `chapters/`. Inside a part, chapters
are numbered so they sort in reading order. Every chapter is a self-contained
Markdown file that should make sense on its own, but also fits in sequence.

## Conventions

- Plain Markdown, no special toolchain required.
- ASCII diagrams over images, so the source stays diff-friendly.
- Each chapter ends with a short "mental model to lock in" recap.
